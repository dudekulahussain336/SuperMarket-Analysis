# SuperMarket-Analysis
This project is an end-to-end Business Intelligence solution built in Power BI to analyze supermarket sales, profitability, returns, and regional performance. Raw transactional data from multiple sources was cleaned and transformed using Power Query, followed by building a structured star-schema data model with proper relationships for accurate analysis.
Tools & Technologies

Power BI, Power Query, DAX, Data Modeling, SQL concepts, Business Intelligence, Data Visualization
This solution enables data-driven decision-making in inventory planning, profitability optimization, and regional strategy while demonstrating end-to-end BI development skills from data preparation to business storytelling.
